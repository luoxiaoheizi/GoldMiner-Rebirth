## 尚需平台账号进行的验收

没有提供微信或抖音小游戏 AppID，本次没有登录平台开发者账号、上传体验版或进行真实手机 SDK 验收。模拟 SDK 与 Chrome 检查不能替代微信 / 抖音开发者工具和 Android / iOS 手机预览。

导入 `dist/wechat`、`dist/douyin` 并填写真实 AppID 后，应在各平台检查：横屏与胶囊避让、触摸出钩、不同静音设置下的音频、切后台和锁屏暂停、杀进程后续玩、连续关卡与商店。

沿用原项目图片和音频的来源说明；代码 MIT 许可与素材商用权分开处理。广告、登录、联网排行、云存档和支付未纳入本次实现。
